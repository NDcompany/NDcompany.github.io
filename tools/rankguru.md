# RankGuru, a free on-page SEO checker

Enter a page's address, or paste its HTML, and RankGuru checks what search engines read first: the title, the meta description, headings, image alt text, links, the canonical and robots tags and structured data. Add up to three competitor pages to see the words they use that your page does not.

## How to use it

### Name the page

Enter the address of the page you want to check, or open Paste HTML and paste the page's source.

### Add competitors

Add up to three competitor pages if you want to compare the words each page uses.

### Run the check

Press Check page. RankGuru reads each page and sorts what it finds into things to fix, things to look at and things that pass.

### Keep the results

Download the results as a CSV file, which any spreadsheet opens.

## Frequently asked questions

**Why does RankGuru say it cannot read a site?**

A browser lets one website read another website's pages only when that site allows it (a rule called CORS), and most sites do not. RankGuru has no server to fetch pages for it, so it says so instead of showing a made-up result. Open the page, view its source (Ctrl+U in Chrome, Edge or Firefox on Windows), copy all of it and paste it into Paste HTML.

**Does RankGuru track my rankings?**

No. It checks how the page itself is written. It does not show where the page ranks in Google or any other search engine; Google Search Console shows that for a site you own.

**Does it see content that JavaScript adds?**

No. It reads the HTML the server sends, before any script runs. If a site builds its content with JavaScript, some text and links can be missing from the check even though Google may see them after it renders the page.

**Is anything sent to N&D Co.?**

No. Your browser fetches the pages and RankGuru checks them on your device. We never see the addresses you check or the results.

**How is this different from an SEO audit?**

RankGuru checks one page at a time against a fixed list of on-page basics. It does not crawl a whole site, measure speed or look at links from other sites. The technical audit in our SEO services starts with a full crawl of the site.
